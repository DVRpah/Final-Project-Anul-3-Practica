# 🐾 DVRVET — Clinică Veterinară Online

Aplicație web pentru gestionarea unei clinici veterinare dezvoltată ca proiect de practică.

## Tehnologii
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** NestJS, PostgreSQL, TypeORM, JWT

## Funcționalități
- Autentificare cu roluri: client, doctor, admin
- Clienții adaugă animale și fac programări
- Doctorii văd programările lor
- Adminul gestionează doctori, servicii și programări
- Dark mode și multilingv RO/RU/EN

## Instalare

```bash
# Backend
cd vet-clinic-backend
npm install
npm run start:dev

# Frontend
cd vet-clinic-frontend
npm install
npm run dev
```
